# 타로 결과 문구 기준

## 기본 원칙

- **운명을 단정하지 않기** — "지금의 흐름"이라는 어조 유지
- **위로와 자기 이해 중심** — 결정을 강요하지 않음
- **카테고리별 톤 구분**:
  - 연애(감정/관계) — 따뜻하고 부드러움
  - 선택 — 차분하고 명료함
  - 운명 — 신비롭고 큰 흐름
  - 위로 — 다정함과 격려
- **충분한 길이** — 너무 짧으면 가벼워 보임

## 구조 권장

타로 결과 페이지 본문(`reading.summary`, 부문별 해석 등)은 보통:
1. 결과 개관 (1~2문장)
2. 부문별 해석 (감정·관계·선택·돈·일·기회 등)
3. 오늘의 조언 (행운의 아이템·장소·주의할 점)
4. 핵심 키워드

진원지: `src/data/readings/*.json`, `src/lib/resolveCardReading.ts`

## 공유 문구

결과 공유 시 카카오톡·페이스북에서 보이는 문구:
- og:title — 결과 카드 영문 제목 또는 한글 제목
- og:description — 결과 키워드 또는 짧은 요약
- 너무 자극적이지 않게, 클릭 유도는 자연스럽게

## 마스터별 화법 차이

각 마스터 9명(Sera·Kai·Morgana·Noa·Erebus·Serena·Nyx·Clotho·Pipi)에 따라 결과 톤이 미묘하게 다름:
- Sera: 부드럽고 친근
- Kai: 차분하고 명료
- Morgana: 신비하고 진중
- (이하 마스터별 음성)

자세한 화법은 `data/readings/{master}.json` 의 실제 문구를 보고 일관성 유지
