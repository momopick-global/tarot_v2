# 유어타로 문구 톤

## 톤 키워드

- **감성적** — 마음을 들여다보는 느낌
- **따뜻함** — 위로·자기 이해 중심
- **신비로운 느낌** — 카드·별빛 모티프 자연스럽게
- **단정하지 않음** — "운명을 절대 피할 수 없다" 같은 표현 금지
- **사용자를 겁주지 않음** — 불안 자극 자제
- **재미 + 자기이해 목적** — 임상 진단처럼 보이지 않게

## 피해야 할 단어·문장

| 회피 | 대안 |
|---|---|
| "반드시 ~할 것이다" | "~할 가능성이 있어요" |
| "무조건" | "지금 흐름에서는" |
| "당신의 운명은 정해졌다" | "지금의 마음이 가리키는 방향" |
| "이것을 무시하면 큰일 난다" | "조금 살펴봐도 좋아요" |
| 의학적 진단 어휘 | "자기 이해의 단서" |

## 권장 표현 패턴

- "~한 흐름일 수 있어요"
- "이런 마음이 떠오를 수 있어요"
- "지금은 ~를 살펴보면 좋아요"
- "오늘의 ~을 가볍게 확인해보세요"

## 면책 문구 (필수 노출 영역)

심리테스트·결과·서비스 안내에서 다음과 같은 면책을 1회 이상 노출:

> 본 콘텐츠는 자기 이해를 돕기 위한 가벼운 해석이며, 의학·심리학적 진단을 대체하지 않습니다. 마음의 어려움이 크다면 전문가의 상담을 권장합니다.

진원지:
- `/psych-tests/` 페이지의 FAQ
- `/psych-tests/{slug}/` 페이지의 "테스트 안내" 박스
- `/psych-tests/{slug}/{resultId}/` 페이지의 면책 문구
- `/disclaimer` 페이지

## 카테고리별 톤 차이

| 카테고리 | 톤 |
|---|---|
| 감정의 방 | 조용·내밀, 마음 들여다보기 |
| 관계의 방 | 따뜻함·조심스러움, 상대 마음 헤아리기 |
| 선택의 방 | 차분·정리, 기준 세우기 |
| 운명의 방 | 신비·흐름, 거대 서사 |
| 위로의 방 | 부드러움·다정함, 작은 한마디 |

## SEO·검색 노출용 문구

- title은 검색 의도 반영 + 브랜드명 ("~~ | 유어타로")
- description은 1~2 문장으로 페이지 핵심 요약
- 메타 키워드는 자연스러운 표현 (스팸 금지)
