# 타로 이미지 스타일

## 톤 키워드

- 유어타로 브랜드에 맞는 **신비로운 타로 감성**
- 별빛·달빛·은은한 빛 입자
- 골드 포인트 액센트
- 부드러운 보라·네이비 베이스
- 인물 일러스트 (실사보다 일러스트풍)
- 두 인물 (커플) 또는 1인 클로즈업

## 피할 것

- 강한 공포 톤 (해골·피·붉은 조명)
- 점집/무속 느낌의 사실적 묘사
- 형광색·강한 원색
- 캐릭터 표정이 위협적·차가운 인상
- 이미지 안에 글자·로고·워터마크

## 이미지 종류별

### 메뉴 카드 (카테고리 서브메뉴 30장)

- 위치: `public/images/tarot-categories/{category}/{slug}.webp`
- 비율: 1:1 정사각형 (권장 1254×1254)
- 톤: 카테고리별 이미지에 이미 짧은 한글 제목 텍스트 합성됨 (예외적 케이스 — 카드 위 시각 텍스트로 활용, sr-only h3와 별개)
- 중앙 정렬, 인물 두 명이 등장하는 감성 일러스트가 일관 톤

### 카테고리 1뎁스 썸네일

- 위치: `public/images/tarot-categories/{categoryId}.webp`
- 비율: 1:1
- 홈 carousel에서 큰 영역에 노출됨
- 5개 카테고리 (emotion/relationship/choice/destiny/comfort) — 정사각형 1254×1254

### 마스터 자원

- 위치: `public/images/masters/{nn_Name}/`
- 파일:
  - `thumb.{png|webp}` — 마스터 카드/리스트 썸네일
  - `bg_01.png` ~ `bg_03.png` — 페이지 배경 (slot 1/2/3)
  - 카드 앞면 (각 마스터 deck) — 별도 폴더 구조
- 마스터 04~09는 아직 png, 01~03 일부 webp 진행 중
- bg는 페이지 위쪽에 자연스럽게 어두워지는 그라데이션 합성

### 결과 페이지 배경

- 위치: `public/images/bg_final.webp`
- 결과 페이지(`/tarot/result`) 전체 배경에 사용

## 마스터 톤 일관성

9명 모두 동일한 일러스트 톤으로 통일:
- Sera (밝은 핑크 톤)
- Kai (블루 톤)
- Morgana (다크 퍼플)
- Noa, Erebus, Serena, Nyx, Clotho, Pipi (각자 키 컬러)

## 결과/마스터/카드 톤 통일

- 같은 일러스트 스타일이어야 함 (서로 다른 일러스트레이터 톤 섞이지 않게)
- 카드 뒷면 1종으로 통일 (`/assets/card-back-page04.webp`)
- 결과 페이지의 모든 시각 요소는 마스터 베이스 컬러와 조화
