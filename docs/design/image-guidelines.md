# 이미지 공통 기준

## 핵심 규칙

| 항목 | 기준 |
|---|---|
| 이미지 안 글자 | **없음** (제목·캐치프레이즈 합성 금지) |
| 로고 | 없음 |
| 워터마크 | 없음 |
| 깨진 이미지 / placeholder | 운영에 노출 금지 |
| 중심 인물 | 모바일 작은 카드에서도 잘 보여야 함 |
| 썸네일 메시지 | 작은 사이즈에서도 의미 전달되어야 함 |
| OG 이미지 | 공유 시 양옆 잘려도 핵심이 보여야 함 (중앙 정렬) |

## 권장 사양

| 용도 | 비율 | 권장 크기 | 형식 |
|---|---|---|---|
| 카드 썸네일 (psych/menu) | 1:1 | 1024×1024 | webp |
| 블로그 본문 썸네일 | 1.4:1 정도 (자유) | 800~1200px wide | webp |
| OG 이미지 | 1.91:1 (1200×630) | 1200×630 | **jpg/png 권장** (Kakao 호환) |
| 마스터 카드 앞면 | 5:7 비율 (1000×1400) | 1000×1400 | webp |
| 마스터 thumb | 1:1 | 600×600 | webp |
| 마스터 배경 (bg_0N) | 9:16 또는 화면 비율 | 1080×1920 | webp |

## fallback 정책

코드(`scripts/generate-blog.js`, `src/lib/blogData.ts`)는 다음 우선순위로 자동 탐색:
1. JSON에서 명시한 경로
2. `/images/{folder}/{slug}.{webp|jpg|jpeg|png}`
3. 카테고리/도메인별 기본 이미지

→ **파일이 없어도 빈 화면이 되지 않도록 코드가 처리**합니다. 그러나 운영 노출용으로는 가급적 모든 페이지에 적절한 이미지를 채워야 합니다.

## 운영 노출 금지

- "이미지 준비중" 텍스트는 dev/fallback 목적 — 운영 빌드에서 보이면 즉시 자원 추가
- 404 이미지 로딩 — 콘솔에 빨간 줄, 브라우저에서 깨진 아이콘
- 단순 그라데이션 + 글자 (값싸 보임)
